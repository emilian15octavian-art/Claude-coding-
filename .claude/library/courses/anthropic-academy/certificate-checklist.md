# Claude Academy: certificate checklist

Catalog read live from https://academy.claude.com/courses on 2026-11-26 (Anthropic Academy moved there from anthropic.skilljar.com).
Refresh any time: `python3 .claude/library/scripts/python/academy.py catalog`.

**How it works:** sign in at academy.claude.com yourself (that's what saves progress and issues the badge). I study the lessons, build
the labs, write your notes, skills and practice quizzes. **You take each course quiz yourself**; I never open or answer graded pages.
When you earn a badge, save it locally in `../../certificates/` (git-ignored: this repo is public).

Legend: 🏅 completion badge · `[ ]` todo · `[~]` studied (notes/skills ready) · `[x]` badge earned (you)
